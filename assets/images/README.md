# Images Folder

## Required: Logo File

Save your company logo in this folder as:

```
assets/images/logo.png
```

The website references `assets/images/logo.png` in:
- The navbar (top left)
- The About section (badge overlay on photo)
- The Footer (brand logo)

### Steps
1. Save your logo image as `logo.png` in this folder
2. Commit and push to GitHub:
   ```bash
   git add assets/images/logo.png
   git commit -m "Add company logo"
   git push
   ```

The logo will automatically appear in all three locations on the site.
